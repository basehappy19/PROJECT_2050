# Project Zero — เวอร์ชันเว็บ

เวอร์ชัน 1.0 · เว็บแอป Preact + canvas + three.js (build ด้วย esbuild)
กฎเกมและข้อมูลอยู่ใน `src/engine/` (แยกออกมาจากเวอร์ชัน GDevelop ตั้งแต่ 1.0 · เวอร์ชัน GDevelop ไม่อัปเดตแล้ว)

ทำไมไม่ย้ายไป Next.js: เกมทำงานในเบราว์เซอร์ทั้งหมด ไม่มีหน้าเว็บให้ server render
Next.js จะเพิ่มขนาดและชั้นของโค้ดโดยไม่ได้ทำให้เกมลื่นขึ้น ส่วนที่หนักจริงคือการวาดแผนที่
ซึ่งแก้แล้วด้วยภาพแคช + ระดับกราฟิก (`src/gfx.js`)

## Build

```
cd web
npm install
node build.mjs                    # build สำหรับเผยแพร่ (ป้องกันโค้ด) → ../index.html, ../sw.js, ../assets/
node build.mjs --open             # build แบบอ่านได้ สำหรับเครื่องมือทดสอบใน tools/
node build.mjs --watch            # build ใหม่อัตโนมัติ + เปิดเว็บที่ http://localhost:5173
P2050_API=https://<server>/api node build.mjs        # ถ้าเว็บไม่ได้อยู่โดเมนเดียวกับ server
P2050_DOMAINS=game.example.ac.th,.github.io node build.mjs   # ให้เกมรันได้เฉพาะโดเมนเหล่านี้ (ขึ้นต้นด้วยจุด = ทุกโดเมนย่อย)
```

### การป้องกันโค้ด (build ปกติ)
- โค้ดถูกย่อและอำพราง (javascript-obfuscator) ชื่อตัวแปรและข้อความถูกซ่อนในตาราง ไม่มี source map
- ตัวเกมไม่อยู่บน `window` แล้ว พิมพ์ในคอนโซลเพื่อแก้ค่าเงินไม่ได้ตรง ๆ
- ตั้ง `P2050_DOMAINS` แล้ว ถ้ามีคนก็อปไฟล์ไปเปิดที่โดเมนอื่น เกมจะไม่ทำงาน
- ฝั่ง server ตั้ง `CORS_ORIGIN` ให้รับเฉพาะโดเมนของเรา สำเนาเถื่อนจะใช้บัญชี/อันดับ/เกียรติบัตรไม่ได้
- ข้อจำกัด: โค้ดที่รันในเบราว์เซอร์ป้องกันได้ 100% ไม่ได้ (คนที่ตั้งใจจริงยังแกะได้ แต่ยากและช้ามาก) ของที่มีค่าจริง ได้แก่ เพชร รางวัล อันดับ เกียรติบัตร คำนวณและตรวจบน server ทั้งหมด
- การอำพรางเลือกค่าที่ไม่ทำให้เกมช้าลง (วัดด้วย `node tools/smoke.mjs` ได้เวลาสคริปต์ใกล้เคียงกับ build ปกติ)

### ทดสอบ
- `node tools/smoke.mjs` — เปิดเกมจาก build ที่ป้องกันแล้ว เล่น ~25 วินาที รายงาน error และเวลาที่ใช้
- `node tools/sim.mjs` — บอทเล่นทั้งเกมหลายรอบ ใช้ปรับความยาก A/B
- `node tools/perf.mjs 1600 900 2 medium` — วัดความลื่นของแผนที่ (ต้อง `--open`)
- `node tools/scene.mjs out.png 1600 900 1 "P.Game.openSkills()"` — ถ่ายภาพหน้าจอเดียว (ต้อง `--open`)

เปิดเล่นผ่าน http server เท่านั้น (เช่น `--watch`, GitHub Pages หรือ Docker ใน `../server`) เปิดไฟล์ index.html ตรง ๆ จะโหลดข้อมูลไม่ได้

## สร้างไฟล์ภาพ/เสียงใหม่ (ไม่ต้องทำถ้าไม่ได้เปลี่ยนต้นฉบับ)

- `node tools/make-world.mjs` — รูปร่างประเทศ (`../assets/data/world.json`)
- `python3 tools/make-textures.py` — ภาพลูกโลกและแผนที่จากภาพ NASA
- `bash tools/make-audio.sh` — เสียงทั้งหมด
- `node tools/tutshots.mjs` — ภาพประกอบหน้า "วิธีเล่น" จากเกมจริง (`node build.mjs --open` ก่อน)
- `node tools/make-icons3d.mjs` — ไอคอน 3 มิติของค่าในเกม (`../assets/img/ui/3d/`)
- ภาพประกอบอีเวนต์ `../assets/img/events/<id>.webp` วาดด้วย Stable Diffusion (sd-turbo) แบบกึ่งสมจริง ตรวจด้วยตาทีละภาพ
- `node tools/shots.mjs <โฟลเดอร์> 1600 900` — ถ่ายภาพทุกหน้าจอไว้ตรวจ

ไฟล์ภาพ เสียง และข้อมูลอยู่ใน `../assets/` โดยตรง (build ไม่ได้คัดลอก) · ที่มาของภาพและเสียง: `../assets/img/CREDITS.txt`, `../assets/audio/CREDITS.txt`
