# Project : 2050 — เวอร์ชันเว็บ

เว็บแอปที่เขียนแยกจาก GDevelop (ไม่ใช่ไฟล์ export) เพื่อให้ภาพคมทุกความละเอียดจอ เต็มจอ และลื่นกว่าเดิม
กฎเกม ข้อมูล และตัวเชื่อม server ใช้ชุดเดียวกับโปรเจกต์ GDevelop (`../gdevelop/_source/src/1x-*.js`, `20-engine.js`, `21-net.js`)
ตอน build จะดึงไฟล์เหล่านั้นมารวมเอง แก้กฎเกมที่เดียวได้ทั้งสองเวอร์ชัน

## โครงสร้าง

| ส่วน | ไฟล์ | ทำอะไร |
|---|---|---|
| หน้าแรก | `src/globe.js` | ลูกโลก 3D (three.js) ภาพถ่ายดาวเทียม NASA กลางวัน/กลางคืน เมฆ ชั้นบรรยากาศ จุดปล่อย CO₂ ลากหมุนได้ กด "เกมใหม่" แล้วกล้องจะบินลงเอเชียตะวันออกเฉียงใต้ |
| ในเกม | `src/map2d.js` | แผนที่ 2D บน canvas วาดตามความละเอียดจอจริง (คมบนจอ Retina/มือถือ) ภาพดาวเทียม + เส้นประเทศ Natural Earth 1:50m ภัยพิบัติมีเอฟเฟกต์ฝน ไฟ คลื่นความร้อน ฯลฯ |
| หน้าจอ | `src/ui/*.jsx` | HUD แถบข้าง หน้าสกิล อีเวนต์ ฉากจบ เลือกตัวละคร เนื้อเรื่อง หยุดเกม หน้าเรียนรู้ เมนู ร้านค้า อันดับ เกียรติบัตร บัญชี (Preact) |
| เสียง | `src/audio.js` | Web Audio แยกช่อง เพลง / บรรยากาศ / เอฟเฟกต์ เพลงเปลี่ยนตามสถานการณ์ (สงบ → ตึงเครียด → วิกฤต) มีเพลงชนะ/แพ้ เสียงพื้นหลังเฉพาะภัยแต่ละชนิด เสียงนาฬิกาช่วง 2 ปีสุดท้าย |
| ควบคุมเกม | `src/game.js` | นาฬิกาเดือน คีย์ลัด (T สกิล · Space หยุด · 1/2/3 ความเร็ว · R/S/N แถบข้าง · H ทั้งโลก · +/− ซูม · F เต็มจอ · Esc) |

## Build

```
cd web
npm install
node build.mjs                    # เขียน ../index.html, ../sw.js, ../assets/
node build.mjs --watch            # build ใหม่อัตโนมัติ + เปิดเว็บที่ http://localhost:5173
P2050_API=https://<server>/api node build.mjs   # ถ้าเว็บไม่ได้อยู่โดเมนเดียวกับ server
```

เปิดเล่นผ่าน http server เท่านั้น (เช่น `--watch`, GitHub Pages หรือ Docker ใน `../server`) เปิดไฟล์ index.html ตรง ๆ จะโหลดข้อมูลไม่ได้

## สร้างไฟล์ภาพ/เสียงใหม่ (ไม่ต้องทำถ้าไม่ได้เปลี่ยนต้นฉบับ)

- `node tools/make-world.mjs` — รูปร่างประเทศ (`../assets/data/world.json`)
- `python3 tools/make-textures.py` — ภาพลูกโลกและแผนที่จากภาพ NASA
- `bash tools/make-audio.sh` — เสียงทั้งหมด
- `node tools/tutshots.mjs` — ภาพประกอบหน้า "วิธีเล่น" จากเกมจริง (build ก่อน)
- `node tools/shots.mjs <โฟลเดอร์> 1600 900` — ถ่ายภาพทุกหน้าจอไว้ตรวจ

ไฟล์ภาพ เสียง และข้อมูลอยู่ใน `../assets/` โดยตรง (build ไม่ได้คัดลอก) · ที่มาของภาพและเสียง: `../assets/img/CREDITS.txt`, `../assets/audio/CREDITS.txt`
