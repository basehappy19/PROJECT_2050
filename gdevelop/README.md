# PROJECT : 2050 — เวอร์ชัน GDevelop

โปรเจกต์นี้แปลงมาจากเวอร์ชันเว็บ (`../index.html`) โดยใช้ **GDevelop 5** (สร้างจาก GDevelop 5.6.269 ควรเปิดด้วยเวอร์ชันนี้หรือใหม่กว่า)

## วิธีเปิด
1. เปิด GDevelop แล้วเลือก **Open a project** แล้วเลือกไฟล์ `game.json` ในโฟลเดอร์นี้
2. กด **Preview** (▶) จะเริ่มที่ฉาก `Loading` จากนั้นแตะหนึ่งครั้งเพื่อเข้าเมนู
3. ถ้าต้องการไฟล์เกมสำหรับส่งงานหรืออัปขึ้นเว็บ ให้ใช้ **File → Export** (HTML5 / Android / Windows)

## โครงสร้าง
| ส่วน | อยู่ที่ไหน |
|---|---|
| ฉาก | `Loading` (โหลดทรัพยากร + แตะเพื่อเข้า), `Menu` (เมนูหลัก), `Game` (ตัวเกม) ความละเอียด 1920×1080 |
| แผนที่โลก 2D | ออบเจกต์ `Ocean`, `MapRim`, `ArcticIce`, `Region` (6 ภูมิภาค), `RegionLine`, `Plume` วางไว้ในฉาก Menu/Game และ `Bubble` ที่สร้างระหว่างเล่น |
| Event ของฉาก | นาฬิกาเกม (ตัวจับเวลา `tick`), การคลิก/แตะ, ปุ่ม Space/Esc, แอนิเมชันควันและฟอง, ดนตรี และการเปลี่ยนฉาก |
| โค้ดหลัก | External events ชื่อ **Core** (ลิงก์ไว้ในฉาก Loading) แบ่งเป็นบล็อก JavaScript 12 บล็อก |
| หน้าจอ/UI | วาดด้วยออบเจกต์ `UIPainter` (Shape painter), `UIText`, `UIIcon` (ไอคอน Lucide 73 แบบ), `TutImage`, `CodeInput` |
| ทรัพยากร | `assets/` = map, ui, icons, fonts (IBM Plex Sans Thai, Chakra Petch, IBM Plex Mono — OFL), audio (ไฟล์เดิม), tutorial (ภาพจับจากเวอร์ชันนี้) |

## แก้เกมตรงไหน
- **ข้อความ ตัวเลข เหตุการณ์**: เปิด External events → `Core` → บล็อก `Data · …` (เหตุการณ์ 152 เรื่องอยู่ในบล็อก `Data · เหตุการณ์ตัดสินใจ 152 เรื่อง`)
- **กติกาการจำลอง** (การปล่อย CO₂, อุณหภูมิ, งบ, คะแนน): บล็อก `Engine · …`
- **ความเร็วเกม**: `SPEEDS` ในบล็อก Engine (วินาทีต่อเดือน) — ฉาก Game ใช้ค่านี้ผ่านตัวแปร `TickSeconds`
- **สีและหน้าตาแผง**: บล็อก `UI toolkit` (ตัวแปร `COL`) และบล็อก `Screens · …`

## ต่างจากเวอร์ชันเว็บ
- ลูกโลก 3 มิติเปลี่ยนเป็น **แผนที่โลก 2D (Robinson)** ลากเพื่อเลื่อนแผนที่ ใช้ล้อเมาส์เพื่อซูม และแตะภูมิภาคเพื่อสั่งการ
- แผงตัวเลข (งบเขียว / ทุนการเมือง / ความนิยม) ย้ายไปอยู่แถบบนเพื่อให้แผนที่กว้างขึ้น
- ในหน้าหยุดเกม รหัสเซฟแสดงเป็นตัวอย่างข้อความ ให้กด “คัดลอกรหัส” ส่วนการวางรหัสยังทำได้ที่เมนูหลัก → โหลดเกม
- กติกา ตัวเลข เหตุการณ์ ข่าว ความสำเร็จ ระบบบันทึก ภาษา TH/EN และเสียงทั้งหมด**เหมือนเดิม**

## โฟลเดอร์ `_source`
ใช้เก็บสคริปต์ที่สร้างโปรเจกต์นี้ (โค้ด JS แยกไฟล์, ตัวสร้าง `game.json`, ตัวสร้างภาพแผนที่/ไอคอน) **ไม่ต้องใช้ตอนเปิดใน GDevelop** ถ้าแก้ใน GDevelop โดยตรง ให้ถือว่า `game.json` คือฉบับล่าสุด
